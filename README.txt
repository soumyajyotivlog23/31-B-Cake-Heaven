Files:
- index.html: website homepage
- bakery-poster.png: poster reference image (if included)

Quick preview:
1. Keep index.html and bakery-poster.png in the same folder.
2. Double-click index.html to open it in a browser.

Publish free using GitHub Pages:
1. Sign in or create a free GitHub account at https://github.com
2. Create a new public repository, e.g. 31b-cake-heaven
3. Upload index.html and bakery-poster.png to the repository root.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch; choose main and /(root), then Save.
6. Wait for the published website URL shown on the Pages settings screen.
GitHub's interface may change; follow the current on-screen instructions.

No paid domain is included. A free GitHub Pages URL will be a github.io address.
This is a static website: it does not process payments or store orders. Orders go to WhatsApp.
